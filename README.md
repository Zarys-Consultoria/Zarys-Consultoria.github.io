# Zarys Institutional Landing Page

Official institutional landing page for **Zarys**, a high-performance consultancy and technology holding. This project serves as our digital front-door, showcasing our expertise in delivering elite solutions, particularly in the medicinal and clinical sectors.

## 🚀 About the Project

Zarys is a newly established consultancy firm (2026) dedicated to bringing world-class, rigorous, and secure technological solutions to the market. Our team possesses extensive experience in handling large-scale multinational infrastructures, supporting millions of users, and managing high-volume operations with extreme excellence.

This project is built to be our foundation for growth, featuring:
- **Clean Architecture:** Component-based structure using React.
- **Modern Stack:** Built with Vite, Tailwind CSS, and TanStack Router.
- **Responsive Design:** Mobile-first approach for healthcare professionals and corporate stakeholders.

## 🛠️ Technical Stack

- **Framework:** React.js
- **Build Tool:** Vite
- **Routing:** TanStack Router
- **Styling:** Tailwind CSS
- **UI Components:** Shadcn UI
- **Language:** TypeScript

## 📂 Project Structure

```text
src/
├── components/     # Reusable UI and Zarys-specific components
├── hooks/          # Custom React hooks
├── lib/            # Utilities and configurations
├── routes/         # Application routing structure
└── styles.css      # Global styles and design system

```

## 🚀 Getting Started

### Prerequisites

* Node.js (v20+ recommended)
* npm

### Installation

1. Clone the repository:
```bash
git clone [https://github.com/davi-zarys/ZarysPage.git](https://github.com/davi-zarys/ZarysPage.git)
cd ZarysPage/home

```


2. Install the dependencies:
```bash
npm install

```


3. Start the development server:
```bash
npm run dev

```


4. Open [http://localhost:8080](https://www.google.com/search?q=http://localhost:8080) to view the application in your browser.
